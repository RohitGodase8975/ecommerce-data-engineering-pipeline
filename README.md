# E-Commerce Data Engineering Pipeline

## Overview
An end-to-end data engineering portfolio project demonstrating how raw e-commerce data can be ingested, cleaned, transformed and prepared for analytics.

## Technologies
- Python and Pandas
- SQL and PostgreSQL
- PySpark
- Google Cloud Storage
- Google BigQuery
- Apache Airflow
- dbt Core
- Docker and Git

## Pipeline
1. Ingest orders, customers and products.
2. Validate data and remove duplicates.
3. Transform records and calculate sales revenue.
4. Store data in a warehouse.
5. Build analytical models and data-quality tests.
6. Orchestrate tasks and prepare sales reporting.

## Example business output
- Total valid orders: 4
- Units sold: 8
- Sample revenue: $151.21

These figures are calculated from the included illustrative dataset.

## Project status
Starter implementation with sample data and code templates. Cloud integrations and full orchestration require configuration and testing.

## Learning objectives
Build practical skills in ETL, SQL, data modeling, data quality, orchestration and cloud data warehousing.
